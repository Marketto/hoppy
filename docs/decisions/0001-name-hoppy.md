# 0001. Product name "Hoppy"
Status: Accepted
Date: 2026-10-14

## Context
Needed a short name that reads naturally in "Send to …" in Italian and English. Candidates
checked informally: HopDoc (taken in telemedicine, "Doc" suggests doctors), Hopfile (close
to an existing "Hop" file-sharing app), Hop-up (airsoft term + existing app).

## Decision
Use **Hoppy**. Existing "Hoppy" trademarks found are for beverages (Japan/US), not software.

## Consequences
Before public launch: formal clearance in EUIPO/TMview, UIBM and USPTO classes 9 and 42,
plus domain and store-name checks. "Hoppy" also means "hop-flavoured" (beer) in English;
accepted for now.
