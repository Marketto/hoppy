# Themes and mascots

The app is minimal: one mascot, one switch, a list, one button. Themes change mood,
not layout. Mascots are generated by `tools/gen_mascots.py` (preview:
`assets/brand/mascots-preview.png`).

## Kawaii (default)

Japanese/Korean cute style ("mochi" bunny): squishy wide body, short ears with one folded
tip, tiny dot eyes set wide and low with a single shine, ㅅ mouth, blush ovals with manga
hatch lines, little paws, thin warm cocoa outline.

| Role | Color |
| --- | --- |
| Background | `#FFF6F3` mochi cream |
| Surface container | `#FFEAE5` |
| Primary | `#F0859A` strawberry milk |
| Primary container | `#FFDDE3` |
| Secondary | `#A98BD9` lavender |
| Text | `#4A3530` cocoa |
| Muted text | `#8A6E66` |
| Mascot outline | `#6B4E45` |

Shapes: 24dp corners, pill buttons. Tone of copy: friendly, short ("Delivered ✓").

## Pro

Stylized flat bunny: geometric light-grey head, tall straight ears, black wayfarer
sunglasses with a teal top line and glass highlights, small smirk. No outline.

| Role | Color |
| --- | --- |
| Background | `#121316` graphite |
| Surface container | `#202126` |
| Primary | `#4FD1C5` teal |
| Primary container | `#173F3B` |
| Text | `#E9E9EC` |
| Muted text | `#9A9AA3` |

Shapes: 10dp corners. Tone of copy: same words, no emoji in UI chrome.

## Rules

- Original characters only; they must not resemble existing mascots or brands.
- Colors come from theme attributes in code, never hard-coded in layouts.
- Next steps: rounded typeface for Kawaii (e.g. a Google Font via downloadable fonts),
  small mascot reactions (hop on delivered, already in `SendActivity`), dark Kawaii variant.
