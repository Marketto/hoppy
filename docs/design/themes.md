# Themes and mascots

The app is minimal: one mascot, one switch, a list, one button. Themes change mood,
motion and decoration, never the layout or the features. Approved comps: the design
canvas "Hoppy · proposte stile pubblicità giapponese" (four animated proposals). Mascot
preview: `assets/brand/mascots-preview.png`.

## Choosing a theme

- First launch opens `ThemePickerActivity` (Android has no install-time UI): five live,
  animated cards; the user picks one. It can be changed later from the ⋮ menu.
- The pre-selected card comes from the OS (`ThemeSuggestion`): **high contrast → Manga**,
  else **dark mode → Night**, else **Purikura**. The card shows why it was suggested.
- People upgrading from the two-theme build keep their choice (Kawaii → Purikura,
  Pro → Night) and skip the picker.

## Mascots

Generated by `tools/gen_mascots.py` — never edit the outputs.

- `mascot_kawaii` — mochi bunny (Purikura, Showa, Manga, Yume); `mascot_happy` — closed
  "^ ^" eyes and open mouth, used to celebrate a delivery; `mascot_pro` — cool bunny with
  sunglasses (Night).
- Named groups animate natively via `mascot_<name>_anim.xml` (AnimatedVectorDrawable):
  ears wiggle, eyes blink, cheeks blush, sunglasses glint. Body motion (hop, bob, sway,
  nod, celebrate) is done in `MascotView`.

## Code map (Android)

`apps/android/app/src/main/java/app/hoppy/ui/theme/`: `HoppyTheme` (enum + style +
mascot + migration), `ThemeSuggestion` (pure rules + `SystemThemeSignals` reader),
`ThemeBackgroundView`, `MascotStageView`, `MascotView`, `HoppyButton`, `ShineDrawable`,
`ButtonFx`, `HomeDecor`, `Motion` (ticker, `HostAware`, fonts). Styles in
`res/values/themes.xml`; the `hoppyThemeKind` attr enum order must match `HoppyTheme`.

## Rules

- Original characters only; they must not resemble existing mascots or brands.
- Colors come from theme attributes or `HoppyTheme`; never hard-coded in layouts.
- Motion: every animation stops in `onStop`, on detach and when hidden, and is off when
  the system "remove animations" setting is on. Custom animated views implement `HostAware`.
- Any new Japanese text needs `python3 tools/fonts.py` (fonts are subsetted).
- **Accessibility (WCAG 2.2 AA)**: text ≥ 4.5:1, large text and state-bearing UI ≥ 3:1, in
  every theme. Pastel colors are for decoration only; anything carrying text uses the deeper
  shades above. `python3 tools/contrast.py` (part of `dev.py check`) checks every theme
  text/background pair — add new pairs there. Manga must stay the highest-contrast theme.
